# How This Wiki Works

This vault is built so you can jot things down **during** a session without stopping to think about structure, and clean it up later if you feel like it (you don't have to).

## The Folders

- **Characters/Party** - the PCs. One page each.
- **Characters/NPCs** - everyone else with a name. One page each, even if it's two lines.
- **Characters/Companions** - pets, familiars, mounts, adopted goblins.
- **Locations** - towns, dungeons, buildings, regions.
- **Factions** - cults, houses, guilds, clans, churches.
- **Items and Lore** - notable gear, world history, big mysteries.
- **Quests** - the [[Quest Log]], one running page.
- **Sessions** - one page per session.
- **Templates** - starter layouts, see below.

## Adding Notes _During_ Play (the important part)

**Fastest option - just type a link.** In any note (even the Session page for tonight), type two open square brackets and start typing a name. If the page doesn't exist yet, Obsidian will offer to create it. Hit enter, and you now have a blank page linked from wherever you were. Come back and fill it in later, or never - a red/unresolved link is still useful as a "we mentioned this, follow up" marker.

**To start a new session note fast:**

1. In Obsidian, turn on the core **Templates** plugin (Settings → Core plugins → Templates) and set the template folder to `Templates`.
2. Create a new file in `Sessions` (e.g. `Session 09`).
3. Open the command palette (Ctrl/Cmd+P) → **"Insert template"** → pick `Session Template`.
4. Leave it open in a side pane on your phone/laptop and just add bullet points as things happen. Don't worry about prose - bullets are fine, you can tidy later.

**To add an NPC/location/item the moment it comes up:**

- Type the name in double square brackets in your session note.
- Click the link, choose **NPC Template** / **Location Template** / **Item Template** / **Faction Template** from the template picker, and fill in what you know. Two sentences is a complete entry.

## Tags

Every page has a `tags:` line up top (`npc`, `location`, `session`, etc.) so you can use Obsidian's search (`tag:#npc`) or the Graph View filters to see just one category.

## Suggestion

Keep [[Mysteries and Plot Threads]] and [[Quest Log]] open in a pinned tab during sessions - they're the two pages most worth updating live, since "wait, why does that matter again?" is exactly what they're for.
